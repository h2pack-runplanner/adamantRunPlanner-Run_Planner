# Execution-plan fixtures

These files are byte-for-byte mirrors of the corresponding execution fixtures
in RunPlanner-main. They cover the fixed-route navigation products, automatic
effects, the Surface scheduled lifecycle, and planner-generated encounter
compositions (expected budgets, highlight, Fangs, Menace, template companions
and an authored base roll) used for cross-product protocol proof. They are
checked-in protocol data; Plan Executor tests never import planner
implementation code.
